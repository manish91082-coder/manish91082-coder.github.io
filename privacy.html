Privacy policy

Last updated: 26 October 2026

Ghost Hunter is a private tool used only by its owner. It uses Google sign-in solely so that the owner's own server can upload its own log files to the owner's own Google Drive.

What data is accessed

The tool uses Google Drive access only to create folders and upload log files into the signed-in owner's Drive, and to list those folders to confirm an upload succeeded. It does not read, change or delete any other files.

What is collected or shared

No personal data is collected, sold or shared with anyone. No data is sent to any third party. The sign-in token is stored only on the owner's own server.

Removing access

Access can be removed at any time from the Google account's security settings (Third-party apps with account access).
